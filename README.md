Objetivo 

Esse site tem como objetivo mostrar as tecnologias usadas no campo. Mostra os exemplos de tecnologias como drones e sensores.

Instruções

No cemeço vai ter uma caixa perguntando seu nome e embaixo vai ter as tecnologias. Lá em cima vai ter dois botões um de aumentar e outro de diminuir a fonte.

Tecnologias usadas

HTML
CSS
JavaScript

Justificativa

Esse site foi feito para informar usuarios quais são as tecnologias que os agricultores usam no campo. Mostrando e esplicando de forma educativa.
